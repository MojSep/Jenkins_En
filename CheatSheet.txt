1. Architecture & Core Concepts
1.1 Component model
text

┌──────────────────────────────────────────────────────────────────┐
│                        Reverse Proxy (nginx/ALB)                 │
│                        TLS termination, :443                     │
└─────────────────────────────┬────────────────────────────────────┘
                              │ X-Forwarded-*
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    Jenkins Controller (JVM)                      │
│  :8080 (HTTP, loopback)   :50000 (JNLP agents)                   │
│  $JENKINS_HOME = /var/lib/jenkins                                │
│  numExecutors: 0  ← controller builds NOTHING                    │
└─────────┬───────────────────────────────┬────────────────────────┘
          │                               │
   ┌──────▼───────┐  ┌─────────────┐  ┌──▼───────────────┐
   │ Static agent │  │ SSH agent   │  │ K8s dynamic pods │
   │ (VM)         │  │ (VM)        │  │ (namespace)      │
   └──────────────┘  └─────────────┘  └──────────────────┘

Golden rules:

    Controller: numExecutors: 0 — never build on the controller in production.

    Agents scale; controller stays stable.

    All state on $JENKINS_HOME — back it up.

    Secrets encrypted with secret.key — never lose it.

1.2 Execution flow
text

Webhook/Poll → Queue → Executor (agent) → Build → Post-build → Archive/Notify
                 │                          │
                 └─ throttled by            └─ durable task (survives restart)
                    numExecutors

1.3 Key concepts cheat
Term	Meaning
Controller	Main Jenkins process; serves UI + API; orchestrates
Agent	Executor machine (VM, container, pod) that runs builds
Executor	Thread slot on an agent that runs one build at a time
Workspace	Per-job per-agent dir ($JENKINS_HOME/workspace/<job> on controller)
Pipeline	Groovy DSL defining build stages (Declarative or Scripted)
Multibranch	Auto-discovers branches + PRs from SCM
Shared Library	Reusable Groovy code (@Library('name'))
Credentials	Encrypted store; referenced by id
Global Tool	Managed JDK/Maven/Node/etc. installed per-agent
Cloud	Agent provisioner (Kubernetes, Docker, EC2, Azure)
2. Critical Paths & Files
2.1 $JENKINS_HOME layout
text

$JENKINS_HOME/                                    # default /var/lib/jenkins
├── config.xml                                    # global system config
├── credentials.xml                               # encrypted credentials store
├── secret.key                                    # ★ master AES key
├── secret.key.not-so-secret                      # HMAC salt
├── identity.key.enc                              # ★ instance RSA key
├── hudson.model.UpdateCenter.xml                 # update site URL
├── jenkins.model.JenkinsLocationConfiguration.xml # Jenkins URL + admin email
├── jenkins.security.csrf.GlobalCrumbIssuerConfiguration.xml
├── jenkins.CLI.xml                               # CLI over remoting toggle
├── queue.xml                                     # build queue state
├── nodeMonitors.xml
├── jobs/
│   └── <JOB>/
│       ├── config.xml                            # job definition
│       ├── nextBuildNumber
│       ├── builds/<N>/build.xml
│       ├── builds/<N>/log
│       └── workspace/
├── nodes/<NAME>/config.xml
├── users/<USER>/config.xml                       # profile + API tokens
├── secrets/
│   ├── initialAdminPassword                      # first-boot only
│   ├── hudson.util.Secret                        # ★ encrypted master secret
│   ├── master.key
│   └── file-name-secrets/
├── plugins/
│   ├── <plugin>.hpi                              # or .jpi
│   └── <plugin>/META-INF/
├── updates/default.json                          # update-center cache
├── init.groovy.d/                                # boot scripts (alphabetical)
│   └── *.groovy
├── fingerprints/
├── logs/
├── war/                                          # exploded WAR (if not --webroot)
└── workspace/                                    # controller-side workspaces

2.2 System paths outside $JENKINS_HOME
Path	Purpose
/etc/default/jenkins (Debian)	JENKINS_HOME, JENKINS_PORT, JAVA_ARGS, JENKINS_ARGS
/etc/sysconfig/jenkins (RHEL legacy)	same
/usr/lib/systemd/system/jenkins.service	systemd unit
/etc/systemd/system/jenkins.service.d/*.conf	drop-ins (production overrides)
/usr/share/jenkins/jenkins.war (Deb) / /usr/lib/jenkins/jenkins.war (RPM)	WAR
/var/cache/jenkins/war/	exploded WAR (--webroot)
/var/log/jenkins/jenkins.log	main log
/etc/nginx/conf.d/jenkins.conf / /etc/httpd/conf.d/jenkins.conf	proxy
/etc/ssl/certs/ / /etc/pki/tls/	TLS material
2.3 Filesystem permissions (production baseline)
bash

chown -R jenkins:jenkins /var/lib/jenkins
chmod 750 /var/lib/jenkins
chmod 700 /var/lib/jenkins/secrets
chmod 600 /var/lib/jenkins/secret.key
chmod 600 /var/lib/jenkins/identity.key.enc
chmod 600 /var/lib/jenkins/credentials.xml
chmod 640 /var/lib/jenkins/config.xml
find /var/lib/jenkins -type f -name '*.xml' -exec chmod 640 {} \;

2.4 Sensitivity matrix
File	Sensitivity	Hand-edit safe?
secret.key, identity.key.enc, secrets/*	★ CRITICAL	❌ Never
credentials.xml	★ CRITICAL	❌ Never — use UI/API/JCasC
config.xml	High	⚠️ Only with Jenkins stopped + reload
jobs/*/config.xml	Medium	✅ With reload, or via API
nodes/*/config.xml	Medium	⚠️ Restart / UI
jenkins.yaml (JCasC)	High	✅ Version-controlled, hot reload
init.groovy.d/*.groovy	High	✅ Review carefully — runs as SYSTEM
hudson.model.UpdateCenter.xml	Medium	✅ Restart
3. Installation Quick Reference
3.1 Debian/Ubuntu (online)
bash

sudo apt-get update && sudo apt-get install -y fontconfig openjdk-17-jre-headless
sudo mkdir -p /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/jenkins-keyring.asc https://pkg.jenkins.io/debian-stable/jenkins.io-2023.key

3.5 Offline (air-gap) — one-liner
bash

# staging (online)
curl -fsSLO https://get.jenkins.io/war-stable/2.479.1/jenkins.war
curl -fsSL -o jenkins-plugin-manager.jar \
  https://github.com/jenkinsci/plugin-installation-manager-tool/releases/latest/download/jenkins-plugin-manager.jar
printf '%s\n' configuration-as-code kubernetes workflow-aggregator git \
  credentials-binding role-strategy ldap script-security junit warnings-ng \
  slack timestamper build-timeout ws-cleanup prometheus > plugins.txt
java -jar jenkins-plugin-manager.jar --war jenkins.war --plugin-file plugins.txt \
  --plugin-download-directory ./plugins --latest false --clean-target-dir
tar czf offline.tgz jenkins.war plugins/

# target (offline)
tar xzf offline.tgz
sudo cp jenkins.war /opt/jenkins/ && sudo -u jenkins cp plugins/*.hpi /var/lib/jenkins/plugins/
sudo chown -R jenkins:jenkins /var/lib/jenkins/plugins /opt/jenkins
sudo systemctl enable --now jenkins

6.3 Common API operations
bash

BASE=https://jenkins.example.com
AUTH="-u admin:$TOKEN"

# list jobs
curl -sS $AUTH "$BASE/api/json?tree=jobs[name,url,color]" | jq .

# job info
curl -sS $AUTH "$BASE/job/foo/api/json?tree=name,lastBuild[number,result]" | jq .

# last build status
curl -sS $AUTH "$BASE/job/foo/lastBuild/api/json?tree=number,result,duration" | jq .

# console log
curl -sS $AUTH "$BASE/job/foo/lastBuild/consoleText"

# trigger build with params
curl -sS $AUTH -X POST "$BASE/job/foo/buildWithParameters?BRANCH=main&ENV=prod"

# trigger and wait (max 600s)
curl -sS $AUTH -X POST "$BASE/job/foo/build?delay=0sec"
# poll lastBuild until !building
until [ "$(curl -sS $AUTH "$BASE/job/foo/lastBuild/api/json?tree=building" | jq -r .building)" = "false" ]; do sleep 5; done

# create job from XML
curl -sS $AUTH -X POST "$BASE/createItem?name=bar" \
  -H "Content-Type: application/xml" --data-binary @job.xml

# get/update job XML
curl -sS $AUTH "$BASE/job/foo/config.xml" -o foo.xml
curl -sS $AUTH -X POST "$BASE/job/foo/config.xml" \
  -H "Content-Type: application/xml" --data-binary @foo.xml

# copy job
curl -sS $AUTH -X POST "$BASE/createItem?name=bar&mode=copy&from=foo"

# delete job
curl -sS $AUTH -X POST "$BASE/job/foo/doDelete"

# disable/enable
curl -sS $AUTH -X POST "$BASE/job/foo/disable"
curl -sS $AUTH -X POST "$BASE/job/foo/enable"

# queue
curl -sS $AUTH "$BASE/queue/api/json?tree=items[id,task[name],why]" | jq .
curl -sS $AUTH -X POST "$BASE/queue/cancelItem?id=42"

# agents
curl -sS $AUTH "$BASE/computer/api/json?tree=computer[displayName,offline,idle]" | jq .
curl -sS $AUTH -X POST "$BASE/computer/agent-1/toggleOffline?offlineMessage=maintenance"

# plugins
curl -sS $AUTH "$BASE/pluginManager/api/json?tree=plugins[shortName,version,enabled]" | jq .
curl -sS $AUTH "$BASE/pluginManager/api/json?tree=plugins[shortName,version,dependencies[shortName,version]]" | jq .

# credentials (metadata only — secrets never returned)
curl -sS $AUTH "$BASE/credentials/store/system/domain/_/api/json?tree=credentials[id,typeName,description]" | jq .

# nodes / executors / load
curl -sS $AUTH "$BASE/computer/api/json?tree=busyExecutors,totalExecutors" | jq .
curl -sS $AUTH "$BASE/overallLoad/api/json" | jq .

7. Pipeline Patterns
7.1 Declarative skeleton (production-grade)
groovy

@Library('company-pipeline-lib@v1.2.3') _

pipeline {
  agent { label 'docker && linux && x86_64' }
  options {
    timestamps()
    timeout(time: 30, unit: 'MINUTES')
    buildDiscarder(logRotator(numToKeepStr: '30', artifactNumToKeepStr: '10'))
    disableConcurrentBuilds()
    skipDefaultCheckout(false)
    durabilityHint('PERFORMANCE_OPTIMIZED')
    ansiColor('xterm')
  }
  environment {
    APP          = 'my-service'
    REGISTRY     = 'registry.example.com'
    IMAGE_TAG    = "${env.GIT_COMMIT.take(8)}-${env.BUILD_NUMBER}"
  }
  parameters {
    choice(name: 'ENV', choices: ['dev','staging','prod'], description: 'Deploy target')
    booleanParam(name: 'RUN_E2E', defaultValue: true, description: 'Run E2E suite')
    string(name: 'BRANCH', defaultValue: 'main')
  }
  stages {
    stage('Checkout') {
      steps { checkout scm }
    }
    stage('Build') {
      steps {
        sh '''
          set -eu
          ./mvnw -B -ntp clean verify -DskipTests
        '''
      }
    }
    stage('Test') {
      parallel {
        stage('Unit') {
          steps { sh './mvnw -B -ntp test' }
          post { always { junit '**/target/surefire-reports/*.xml' } }
        }
        stage('Static Analysis') {
          steps { sh 'make lint' }
          post { always { recordIssues tools: [checkStyle()] } }
        }
      }
    }
    stage('Docker Build & Push') {
      when { branch 'main' }
      steps {
        withCredentials([usernamePassword(credentialsId: 'registry-push', usernameVariable: 'RU', passwordVariable: 'RP')]) {
          sh '''
            echo "$RP" | docker login -u "$RU" --password-stdin "$REGISTRY"
            docker build -t "$REGISTRY/$APP:$IMAGE_TAG" .
            docker push "$REGISTRY/$APP:$IMAGE_TAG"
          '''
        }
      }
    }
    stage('Deploy') {
      when { expression { params.ENV != 'prod' || currentBuild.upstreamBuilds } }
      steps {
        withCredentials([file(credentialsId: 'kubeconfig-prod', variable: 'KCFG')]) {
          sh 'KUBECONFIG=$KCFG kubectl --namespace "$ENV" set image deploy/$APP app=$REGISTRY/$APP:$IMAGE_TAG'
        }
      }
    }
  }
  post {

}

11.2 Backup (hot, consistent)
bash

#!/usr/bin/env bash
# /usr/local/bin/jenkins-backup.sh — run from cron as jenkins
set -euo pipefail
TS=$(date +%F_%H%M)
DST=/var/backups/jenkins
JH=/var/lib/jenkins
mkdir -p "$DST"

# 1. Quiet down (drain builds) — optional but recommended
# curl -fsS -u "admin:$TOKEN" -X POST http://localhost:8080/quietDown
# while curl -sS -u "admin:$TOKEN" http://localhost:8080/queue/api/json | grep -q '"items":\[.'; do sleep 10; done

# 2. Copy state (tar preserves ownership/modes)
tar czf "$DST/jenkins-$TS.tgz" \
  -C "$JH" --exclude='workspace' --exclude='war' \
  config.xml credentials.xml secret.key secret.key.not-so-secret \
  identity.key.enc secrets/ jobs/ users/ nodes/ plugins/ \
  hudson.model.UpdateCenter.xml init.groovy.d/ scriptApproval.xml \
  jenkins.yaml 2>/dev/null || true

# 3. Manifest
tar tzf "$DST/jenkins-$TS.tgz" | sha256sum > "$DST/jenkins-$TS.sha256"

# 4. Retention — keep 14 daily + 8 weekly
find "$DST" -name 'jenkins-*.tgz' -mtime +30 -delete

# 5. Unquiet
# curl -fsS -u "admin:$TOKEN" -X POST http://localhost:8080/cancelQuietDown

bash

# cron: nightly at 02:15
15 2 * * * jenkins /usr/local/bin/jenkins-backup.sh >> /var/log/jenkins-backup.log 2>&1

11.3 Restore (disaster recovery)
bash

# 1. Stop
sudo systemctl stop jenkins

# 2. Preserve broken state for post-mortem
sudo mv /var/lib/jenkins /var/lib/jenkins.broken.$(date +%F_%H%M)

# 3. Restore
sudo mkdir -p /var/lib/jenkins
sudo tar xzf /var/backups/jenkins/jenkins-YYYY-MM-DD_HHMM.tgz -C /var/lib/jenkins
sudo chown -R jenkins:jenkins /var/lib/jenkins

# 4. Restore WAR/plugins to match — if plugins/ was restored, WAR must match
#    the version Jenkins-Version in manifests expects
sudo cp /opt/jenkins/jenkins.war /usr/share/jenkins/jenkins.war

# 5. Start + verify
sudo systemctl start jenkins
sleep 30
curl -fsS -o /dev/null -w '%{http_code}\n' http://localhost:8080/login
curl -sS -u admin:$TOKEN http://localhost:8080/api/json?tree=version | jq .
sudo grep -iE 'UnsatisfiedDependency|HudsonFailedToLoad' /var/log/jenkins/jenkins.log || echo OK

# 6. Unquiet (if you quieted before backup)
curl -sS -u admin:$TOKEN -X POST http://localhost:8080/cancelQuietDown

14. Upgrade & Rollback
14.1 Pre-flight
bash

# 1. Read changelog + security advisories
# https://www.jenkins.io/changelog-stable/
# https://www.jenkins.io/security/advisories/

# 2. Check plugin compatibility for target core
java -jar jenkins-plugin-manager.jar --war jenkins-new.war \
  --plugin-file plugins.txt --list

# 3. Confirm target Java version
java -version  # LTS >= 2.479 requires 17 or 21

# 4. Snapshot
sudo tar czf /var/backups/jenkins-pre-upgrade-$(date +%F_%H%M).tgz -C /var/lib jenkins/

14.2 Upgrade (offline-safe)
bash

# 1. Quiet down + wait
curl -u admin:$TOKEN -X POST http://localhost:8080/quietDown
until [ "$(curl -sS -u admin:$TOKEN 'http://localhost:8080/computer/api/json' | jq '[.computer[].executors[].currentExecutable]|map(select(.!=null))|length')" = "0" ]; do sleep 15; done

# 2. Stop
sudo systemctl stop jenkins

# 3. Backup (already done in pre-flight, but redo now that nothing is changing)
sudo tar czf /var/backups/jenkins-pre-swap-$(date +%F_%H%M).tgz -C /var/lib jenkins/

# 4. Swap WAR
sudo cp /opt/jenkins/jenkins-new.war /usr/share/jenkins/jenkins.war

# 5. Swap plugins (if the new set is pinned differently)
sudo rm -rf /var/lib/jenkins/plugins/*
sudo -u jenkins cp /opt/jenkins/plugins-new/*.hpi /var/lib/jenkins/plugins/

# 6. Start
sudo systemctl start jenkins

# 7. Wait for readiness
for i in $(seq 1 60); do
  curl -fsS -m 3 -u admin:$TOKEN 'http://127.0.0.1:8080/api/json?tree=mode' >/dev/null 2>&1 && break
  sleep 5
done

# 8. Verify
curl -sS -u admin:$TOKEN http://localhost:8080/api/json?tree=version | jq .
sudo grep -iE 'UnsatisfiedDependency|HudsonFailedToLoad' /var/log/jenkins/jenkins.log || echo OK
curl -u admin:$TOKEN -X POST http://localhost:8080/cancelQuietDown

14.3 Rollback (fast)
bash

sudo systemctl stop jenkins
# restore the pre-swap snapshot in one go
sudo rm -rf /var/lib/jenkins
sudo tar xzf /var/backups/jenkins-pre-swap-YYYY-MM-DD_HHMM.tgz -C /var/lib
sudo chown -R jenkins:jenkins /var/lib/jenkins
# restore matching WAR
sudo cp /opt/jenkins/jenkins-old.war /usr/share/jenkins/jenkins.war
sudo systemctl start jenkins

Rollback is all-or-nothing — restoring plugins/ without the matching secret.key/WAR corrupts the instance.

Quarterly	Full plugin audit; uninstall unused; DR restore test
Annually	Major core LTS line review (Java 17 → 21, etc.)

ps -eo pid,args | grep -i 'jenkins.war' | grep -v grep

# 2. resources

# 3. ports

# 5. config integrity

15.2 Symptom → cause → fix (reference)
Symptom	Likely cause	Fix
Unit failed immediately	unit/env/JVM flag	journalctl -u jenkins -b -n 200; §4.1
Hangs in activating	slow init (plugins/jobs/LDAP) or OOM	grep -i startup; raise TimeoutStartSec; find slow phase
Unrecognized VM option	obsolete flag	remove from JAVA_OPTS
UnsupportedClassVersionError	wrong JDK	update-alternatives --config java
Could not reserve enough space for heap	-Xmx > RAM/cgroup	lower -Xmx, or raise cgroup limit
AccessDeniedException	ownership / SELinux	chown -R jenkins:jenkins; ausearch -m avc
No space left on device	disk/inodes full	df -h; df -i; purge builds/workspaces
Address already in use	port conflict	ss -ltnp; change port
UnsatisfiedDependencyException	missing plugin dep	re-resolve plugins.txt; swap while stopped
requires Jenkins 2.xxx	core too old	upgrade core in window
ClassNotFoundException	plugin skew / disabled	pluginManager/api/json
HudsonFailedToLoad	init failed (broad)	full startup log tail
Login always fails	LDAP/AD/OIDC/SAML	ldapsearch; check jenkinsUrl
All users 403	role-strategy / authz	restore authz or JCasC
Could not decrypt credentials	secret.key mismatch	restore key+creds together
Jobs missing / red	job XML vs plugins	find jobs -name config.xml + xmllint
reverse proxy broken	jenkinsUrl mismatch	fix JenkinsLocationConfiguration.xml
Agents can't connect	50000 blocked / WS disabled	open port; or enable WebSocket launcher
OOM after start	heap too small / leak	.hprof in /var/log/jenkins/; raise -Xmx
Restart loop	failing init	StartLimitBurst + fix root cause
15.3 Emergency admin recovery
bash

# 1. Stop
sudo systemctl stop jenkins
sudo cp /var/lib/jenkins/config.xml /var/backups/config.xml.$(date +%F_%H%M)

# 2. Temporarily disable security (last resort only)
sudo sed -i 's#<useSecurity>true</useSecurity>#<useSecurity>false</useSecurity>#' /var/lib/jenkins/config.xml
sudo systemctl start jenkins
# → log in anonymously, restore auth, re-enable, restart

groovy

// Alternative: init.groovy.d/00-breakglass.groovy (delete after recovery!)
import jenkins.model.*
import hudson.security.*
def i = Jenkins.get()
def realm = new HudsonPrivateSecurityRealm(false)
realm.createAccount("breakglass","ROTATE_ME_NOW")
i.setSecurityRealm(realm)
i.setAuthorizationStrategy(new FullControlOnceLoggedInAuthorizationStrategy())
i.save()

    Delete the groovy file and the account after recovery. Rotate credentials.

15.4 Rotate secret.key (advanced)

Only when leaked. Procedure:
bash

# 1. Stop
sudo systemctl stop jenkins
# 2. Backup
sudo tar czf /var/backups/jenkins-keys-$(date +%F).tgz -C /var/lib jenkins/
# 3. Move old keys aside
sudo mv /var/lib/jenkins/secret.key{,.old}
sudo mv /var/lib/jenkins/identity.key.enc{,.old}
# 4. Start — Jenkins generates a NEW secret.key, but credentials.xml ciphertext is now unreadable
sudo systemctl start jenkins
# 5. Re-enter every credential via UI/JCasC/Vault
# 6. Delete old credentials.xml after re-entry

Prefer migrating to Vault instead of doing this in place.

18. Production Golden Rules (one-page summary)

    Pin everything — core WAR, plugin versions, Docker image digest, JDK.

    Controller builds nothing — numExecutors: 0; workloads on agents/K8s.

    JCasC is the source of truth — jenkins.yaml + plugins.txt in git.

    Secrets in Vault/SM, not in credentials.xml where avoidable.

    secret.key + identity.key.enc + credentials.xml are Tier-0 — back up together, never hand-edit.

    script-security ON, CLI off, JNLP scoped — reduce attack surface.

    Reverse proxy terminates TLS; controller on loopback.

    Backup nightly; restore tested quarterly — untested backups don't exist.

    Upgrade in windows: quiet → wait → backup → swap → readiness → unquiet.

    Monitor /prometheus + /login + log signatures; alert on restart loops, heap, disk, HudsonFailedToLoad.

    Discard builds and clean workspaces in every pipeline — disk is the #1 killer.

    One change per window — bisectable rollbacks beat ambitious upgrades.

    TimeoutStartSec=600 in systemd + startupProbe in K8s — never let liveness kill init.

    Document the break-glass path — locked-out admin is a real outage.

    Rotate API tokens, deploy keys, and TLS certs on a schedule, not on incident.
